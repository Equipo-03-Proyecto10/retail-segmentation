# ADR-0033 — Keep the transport security policy at Flask and NGINX

**Status:** Proposed
**Owner:** Team 03
**Issue:** #359
**Supersedes:** —
**Superseded by:** —

## Context

The deployed NGINX response carried the browser security headers, but direct
Gunicorn, test, and any alternate serving path did not. HSTS had also remained
at a staged 30-day value after the Cloudflare edge certificate became the
stable published certificate. The application and the deployment boundary
must therefore agree on one policy.

This record refines the transport policy used with ADR-0013's Cloudflare
publication decision; it does not replace that decision.

## Decision

Flask sets the security-header baseline on every response, and both NGINX
configurations repeat the same values. NGINX hides Flask's upstream copies
before adding its own headers, so a proxied response contains one value per
policy (rather than duplicate headers with potentially intersecting CSP
directives). HTTPS responses use
`Strict-Transport-Security: max-age=31536000; includeSubDomains`; the policy is
not enabled only by assuming a particular proxy path.

## Alternatives considered

| Alternative | Why it was rejected |
|---|---|
| Keep headers only in NGINX | Direct application and alternate proxy paths would remain weaker than the deployed path. |
| Let Flask be the only source | The reverse proxy is the TLS boundary and must protect errors or responses it generates before Flask. |
| Keep the staged 30-day HSTS value | The published edge certificate is now managed and auto-renewing; the shorter policy no longer matches the transport requirement. |

## Consequences

**What this makes easy.** A response retains the baseline policy whether it is
served by Flask or generated by the proxy, and configuration drift is visible
to tests. The proxy can still select its documented chart CSP exception
without Flask's stricter direct-response CSP intersecting it.

**What this makes hard.** The values must be changed in two layers and kept
identical; the proxy must hide every upstream copy when a policy is added;
HSTS with `includeSubDomains` is a durable browser commitment.

**What must now be true elsewhere.** `deploy/nginx/mosaiq.conf`, the compose
overlay, `web/security.py` and the deployment documentation must keep the
one-year policy and header values aligned.

## Compliance

`tests/test_security.py` checks the Flask response headers,
`tests/test_nginx_security_headers.py` checks both proxy files and their
upstream-header suppression, and the deployment runbook records the one-year
HSTS acceptance check.
