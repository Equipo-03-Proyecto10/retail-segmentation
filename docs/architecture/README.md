**The deployment and infrastructure views overlap on purpose and will drift if
only one is updated.** The deployment view carries the detail a reader needs to
verify a claim (`mosaiq-svc@<name>.service`, ports, the schemas); the
infrastructure view is the picture that reads from the back of a room. A change
to the deployment must edit both.

## What the system is

Two systems share one PostgreSQL database and never call each other.

**The web system** is the first delivery's Flask application, frozen. It runs as
`mosaiq.service` (Gunicorn on `127.0.0.1:8000`), renders HTML on the server and
reads and writes the `public` schema as the role `retail_app`. It uses no Redis
and makes no call to any service ([ADR-0045](../adr/0045-services-never-import-the-web-system.md)).

**Fifteen services** each implement one business rule
([ADR-0034](../adr/0034-fifteen-single-rule-services-each-the-only-service-writer-of-its-data.md),
[ADR-0043](../adr/0043-at-least-ten-microservices-each-implementing-one-business-rule.md)).
Each runs as its own compose project `mosaiq-<name>` under
`mosaiq-svc@<name>.service`, and has its own contract
([ADR-0035](../adr/0035-each-service-publishes-its-own-versioned-contract-and-no-two-services-share-a-resource.md),
[ADR-0040](../adr/0040-each-service-is-built-in-ci-and-runs-as-its-own-compose-project.md)).
Thirteen are the core; `campaigns` and `audit-trail` are the second wave, drawn
with a dashed outline.

## How the parts meet

**No arrow in any diagram joins two services.** Services meet only through
([ADR-0044](../adr/0044-boundaries-meet-only-through-versioned-database-contracts-and-redis-streams.md)):

- **PostgreSQL contracts.** A producer publishes versioned `api_*` objects
  (`*_v1` views and `consume_v1`); a consumer reads those and never the
  producer's tables. A service writes only its own tables, as its own
  `svc_<name>` role. Service-owned data lives in service schemas
  ([ADR-0046](../adr/0046-service-owned-data-lives-in-service-schemas.md)).
- **Redis Streams.** Capture triggers fill eight outboxes
  (`<suffix>_events.outbox`: users, products, categories, stores, stock,
  preferences, sales, segments), keys only. The owning service relays its outbox
  to a stream on `redis-state` with `XADD`; consumers read with consumer groups
  (`XREADGROUP`). The streams are described under [`../../contracts/streams/`](../../contracts/streams/).

The web system's writes fire the same capture triggers, so the services see
what the web changes without the web knowing they exist.

## The datastores

| Store | Where | Holds |
|---|---|---|
| PostgreSQL, database `retail` | the instance, `127.0.0.1:5432` | `public` (29 tables, 4NF), the service schemas, the `api_*` schemas, the eight outboxes |
| `redis-state` | project `mosaiq-infra` | sessions, Redis Streams, rate limits; `noeviction`, AOF |
| `redis-cache` | project `mosaiq-infra` | caches and live counters; `allkeys-lru` |
| MongoDB | project `mosaiq-infra` | in-store engagement, owned by `engagement` alone |

[ADR-0037](../adr/0037-two-redis-instances-carry-sessions-caches-limits-and-inter-service-streams.md)
and [ADR-0038](../adr/0038-mongodb-holds-in-store-engagement-owned-by-engagement-service-alone.md)
decide the Redis and MongoDB roles.

## The two clients and the edge

NGINX terminates TLS and routes: `/` to the web system and
`/api/<name>/` to one loopback port per service, one include per service. The
Android client speaks JSON (Kotlin) and the Electron client speaks XML validated
against an XSD (TypeScript); both send a Bearer token
([ADR-0041](../adr/0041-android-and-electron-clients-run-different-processes-over-different-formats.md)).
Cloudflare and the GCP firewall in front of NGINX are unchanged
([ADR-0013](../adr/0013-publish-mosaiq-through-cloudflare-with-an-origin-certificate.md)).

## The benchmark twin

The Rust twin of the products reads, in [`../../bench/`](../../bench/README.md),
is **bench-only**: it is drawn outside the services, is never registered, never
routed by NGINX and never deployed, and connects as `svc_products_bench`
([ADR-0042](../adr/0042-a-bench-only-rust-build-of-the-products-reads-is-compared-under-one-load.md),
exception E-22). The measurement is in
[`../evidence/products-reads-flask-vs-rust.md`](../evidence/products-reads-flask-vs-rust.md).
