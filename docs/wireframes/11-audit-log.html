  1. Filters by entity and by date range, in the URL like every other list. The AUDITOR reaches this and can read only — no write path anywhere in their nav (permission matrix).
  2. Each row opens a detail with before/after values (screen 12). The list stays scannable; the diff is one click away.
  3. unattributed for any change with no signed-in actor (seed, maintenance script). The log strips password_hash and never carries a credential (RNF-17).
